# Portafolio Profesional

Este repositorio contiene un portafolio personal desarrollado con HTML, CSS y JavaScript. El proyecto utiliza Bootstrap para los estilos responsivos y cuenta con secciones de información personal, estudios, proyectos, lenguajes, intereses y contacto.

## Estructura del proyecto

- `index.html` - Página principal del portafolio.
- `css/bootstrap.min.css` - Archivo Bootstrap descargado para los estilos.
- `js/bootstrap.min.js` - Archivo Bootstrap JS descargado para la interactividad.

## Descripción

El portafolio incluye:
- Sección de bienvenida.
- Información personal del autor.
- Estudios realizados.
- Proyectos y experiencia laboral.
- Lenguajes de programación dominados.
- Áreas de interés profesional.
- Formulario de contacto que guarda los datos localmente usando JavaScript.

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Cómo usar

1. Clona o descarga el repositorio.
2. Abre `index.html` en tu navegador.

> Nota: El formulario de contacto utiliza `localStorage` para guardar los datos en el navegador.
